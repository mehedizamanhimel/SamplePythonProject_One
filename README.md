# SamplePythonProject_One

![Python](https://img.shields.io/badge/Python-3.x-blue)

A Python fundamentals practice project covering core language concepts including classes, loops, conditionals, string operations, and array manipulation. Each concept is isolated in its own script for easy reference and learning.

---

## 🛠 Tech Stack

| Tool | Details |
|---|---|
| Python | 3.x |
| IDE | PyCharm / VS Code |

---

## 📁 Project Structure

```
├── main.py                    → Main entry point
├── ClassOne.py               → Python class and object examples
├── ForLoop.py                → For loop patterns and iterations
├── WhileLoop.py              → While loop examples
├── conditionalStatement.py   → If/elif/else conditional logic
├── stringworks.py            → String methods and operations
└── testarray.py              → Array/list operations and indexing
```

---

## 📚 Topics Covered

- **Classes & Objects** — `ClassOne.py`
- **For Loops** — iteration patterns, range-based loops
- **While Loops** — condition-based looping and break/continue
- **Conditionals** — if/elif/else branching logic
- **Strings** — slicing, formatting, built-in string methods
- **Arrays/Lists** — indexing, appending, iterating

---

## ▶️ How to Run

### Prerequisites

- Python 3.x installed ([python.org](https://www.python.org/downloads/))

### Run any script

```bash
# Clone the project
git clone https://github.com/mehedizamanhimel/SamplePythonProject_One.git
cd SamplePythonProject_One

# Run the main entry point
python main.py

# Or run any individual script
python stringworks.py
python ForLoop.py
```
